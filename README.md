# cozy-gardenia

This repository previously contained Gardenia, a browser-based cozy gardening game. The game files
were removed at the owner's request.

The game is still recoverable from history — it is intact at commit `37d800d`:

```bash
git checkout 37d800d -- .
git commit -m "Restore Gardenia game"
```

GitHub Pages may still be enabled for this repository. With no `index.html` present, the published
site returns 404. To turn it off entirely, set **Settings → Pages → Source** to **None**.
